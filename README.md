# Welcome to math-util Repository

You will find in this repo the following stuff:
- The Math-Util library that offers multiple math functions (a Java-based source code)
- Unit Testing source code with JUnit 5 framework (DDT, CSV parameterized tests)
- Code Coverage with JaCoCo
- GitHub Actions workflow demonstrating Continuous Integration (CI)
- Downloadable build artifact (`.jar`) generated via CI
